# Raw benchmark data

This directory is intentionally excluded from Git. Supply the GraphDTA-format files locally or copy them from durable Google Drive storage:

```text
davis/{ligands_can.txt,proteins.txt,Y}
kiba/{ligands_can.txt,proteins.txt,Y}
```

Record the acquisition source, date, file sizes, and checksums in the split/dataset metadata produced by the preprocessing workflow. Do not edit source files in place.
