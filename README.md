# final_aml_gnn_dta

Simplified MSc dissertation project structure for GNN-based drug-target affinity prediction and AML drug repurposing.

## Workflow
- `data/raw/`: original datasets only; experiment outputs never go here
- `notebooks/`: one notebook per model/experiment from start to finish
- `src/`: reusable preprocessing, model, training, metric, and utility code
- `results/`: metrics, predictions, figures, and checkpoints generated by experiments
